# 선택 온보드 기능: 무수신 자동 감광

대상은 Waveshare ESP32-S3-LCD-3.16이다. 핵심 경로는 PC fixture, USB serial, C receiver, LCD이다. 아래 기능은 `main/feature.c`에 분리했고, `main/main.c`는 수신 시각과 monotonic 시각만 전달한다.

| 후보 | 사용자 가치 | 자원·구현 비용 | 위험 | 시험 | 결정 |
|---|---|---|---|---|---|
| 1. 무수신 자동 감광 | 오래된 값이 계속 표시될 때 화면 밝기를 낮춰 대기 전력을 줄이고 수신 즉시 원래 밝기로 복귀한다. | 기존 GPIO6 active-low LEDC PWM, monotonic 시각, 정적 상태 1개. 추가 부품 없음. | 감광 후 가독성 저하, PWM 극성 오류. | `host/test_feature.c`의 60초 경계·복귀 시험, 운영자 LCD/밝기 관측. | **선택**. 데이터 수신·표시와 결합이 작고 오프라인 재현이 가능하다. |
| 2. IMU 자동 회전 | 보드 방향에 맞춰 UI를 돌린다. | QMI8658 I2C 0x6B, 필터·debounce·회전별 재배치 필요. | 방향 튐, 가로 UI 절단, I2C 장애. | 네 방향 자세·흔들림·복귀 영상. | 제외. 가로 820×320의 정보 밀도와 입력 경로를 먼저 안정화해야 한다. |
| 3. RTC 유지 시계 | USB 분리 중 경과 시간을 계속 표시한다. | PCF85063 I2C 0x51, 초기 시각 설정과 backup 전원 확인 필요. | RTC 미설정·배터리 미장착 시 잘못된 절대 시각. | 전원 제거·복구 뒤 RTC 유효성·unknown 시험. | 제외. 공통 보드 자료는 backup 전원 장착을 보증하지 않는다. |

GPIO6의 active-low 극성과 PWM의 `255 - brightness` 변환은 보드 자료와 제조사 백라이트 BSP에 근거한다. `feature_idle_dimming`은 마지막 검증 frame 수신으로부터 60초에 밝기 100으로 전환하고, 새 frame 수신 시 200으로 되돌린다. 값이 한 번도 수신되지 않았으면 감광하지 않는다. 호스트 시험은 경계와 복귀를 검증한다. 실제 밝기·전력·30초 화면 지속은 운영자 실물 관측이 필요하다.
