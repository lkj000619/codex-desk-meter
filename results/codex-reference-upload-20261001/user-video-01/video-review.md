## 확인 결과

- LCD에서 테스트 사용량 값 58%·82%가 보인다.
- BOOT 조작 장면에 이어 사용량 → 글로벌 리셋 → 진단 → 사용량 전환을 확인했다.
- 진단 화면에서 수신 순번 1, 수신 처리 결과 0, FRAME RECEIVED가 보인다.
- 확인한 표본 장면에서 검은 화면으로 돌아가는 현상은 관찰되지 않았다.
- STALE 및 마지막 정상 값 유지 상태가 표시된다. 실제 계정 사용량 연동을 확인한 것은 아니다.

## 판정 범위

기본 표시 및 세 화면 전환의 실물 증거로 기록한다. 입력 지연, 수신→표시 지연, 긴 입력 동작, 모든 프레임의 연속 안정성은 이번 표본 검토에서 정량 판정하지 않았다. RTC 준비 문구는 전원 차단 후 시간 유지 시험의 증거로 판정하지 않았다.

이 기록을 위해 추가 촬영을 요구하지 않는다. 주요 장면과 상세 관찰은 [video-record.json](video-record.json)에 보존했다. 전체 제품 합격이나 독립적인 단일 실행 비교 점수로 확대 해석하지 않는다.
