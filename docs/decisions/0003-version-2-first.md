# ADR-0003: 버전 2를 최초 기준 장치로 개발

- 상태: 승인
- 결정일: 2026-09-10
- 대체 결정: [ADR-0002: 버전 1을 최초 기준 장치로 개발](0002-version-1-first.md)

## 배경

버전 2에 사용할 Waveshare ESP32-S3-LCD-3.16 보드가 도착했다. 반면 버전 1은
ESP32-S3 Super Mini, ST7735S LCD, 스위치와 저항을 빵판에 배치했지만 실제 회로
구성이 완료되지 않았다.

현재 즉시 bring-up을 진행할 수 있는 일체형 버전 2를 먼저 개발하는 것이
하드웨어 배선 변수를 줄이고 ESP-IDF 환경, 화면, 네트워크와 데이터 흐름을 먼저
검증하는 데 유리하다.

## 결정

초기 제품 구현과 AI 에이전트 비교 실험은 버전 2를 기준으로 진행한다.

- Waveshare ESP32-S3-LCD-3.16을 최초 기준 장치로 사용한다.
- 제조사 기본 펌웨어 또는 예제로 보드와 LCD의 초기 상태를 먼저 검증한다.
- ESP-IDF 기반 빌드와 업로드 절차를 버전 2에서 먼저 확정한다.
- 공통 데이터 모델과 애플리케이션 로직은 향후 버전 1에서 재사용할 수 있도록
  하드웨어 의존 코드와 분리한다.
- 버전 1 회로 구성과 펌웨어 이식은 버전 2 기준 구현 이후 진행한다.
- 버전 1의 미완성 회로는 현재 단계의 합격 조건에 포함하지 않는다.

## 초기 개발 범위

버전 2에서 우선 검증할 범위는 다음과 같다.

1. 보드 모델과 하드웨어 리비전 확인
2. 전원 인가 및 출고 상태 확인
3. USB 연결, 시리얼 로그와 펌웨어 업로드 확인
4. 제조사 ESP-IDF 예제 및 요구 ESP-IDF 버전 확인
5. ST7701 LCD 초기화, 방향, 색상과 백라이트 확인
6. 사용 가능한 내장 입력 장치 확인
7. Wi-Fi 연결, 시간 동기화와 재연결
8. Codex 개인 사용량 및 글로벌 리셋 데이터 표시
9. 캐시, 오래된 데이터와 오류 상태 표시
10. 장시간 동작과 네트워크 장애 복구 검증

## 영향

- 최초 제품 요구사항과 합격 기준은 버전 2를 대상으로 작성한다.
- 320 × 820 세로 화면이 최초 UI 설계 기준이 된다.
- AI 에이전트의 최초 구현 비교에서 버전 1 회로 동작은 평가하지 않는다.
- 버전 1 이식 단계에서 공통 코드와 하드웨어 추상화의 품질을 다시 평가한다.
- ADR-0002는 당시의 결정 이력으로 보존하되 현재 결정으로 사용하지 않는다.

## 버전 1 재개 조건

- 빵판 전원 레일과 공통 GND 구성
- ESP32-S3 Super Mini와 ST7735S의 실제 핀 라벨 확인
- SPI, reset, data/command, chip-select와 백라이트 배선 완료
- 스위치 2개와 10kΩ pull-up 저항 배선 완료
- 전원 인가 전 단락 및 전압 확인

## 후속 확인 사항

다음 bring-up 사실은 2026-09-11에 확인되어 결정의 전제 조건을 충족했다.

- USB-Serial/JTAG가 COM3에서 인식됨
- 출고 로그와 공식 예제가 ESP-IDF v5.3.2 계열임
- LCD 방향·백라이트·BOOT 전환과 RST 재부팅이 확인됨

아직 남은 것은 보드 PCB 리비전, TF 카드와 전체 기능, 장시간 실행, 제품
계약의 C1~C8 실물 시험이다. 이 항목은 [Version 2 bring-up 기록](../hardware/version-2-bring-up.md)과
[제품 계약](../PRODUCT_CONTRACT.md)에서 관리한다.
