# ADR-0002: 버전 1을 최초 기준 장치로 개발

- 상태: 대체됨
- 결정일: 2026-09-05
- 대체일: 2026-09-10
- 대체 결정: [ADR-0003: 버전 2를 최초 기준 장치로 개발](0003-version-2-first.md)

> 2026-09-10에 Waveshare ESP32-S3-LCD-3.16 보드가 도착하여 이 결정을
> ADR-0003으로 대체했다. 아래 내용은 당시의 판단 근거를 보존한 기록이다.

## 배경

프로젝트는 두 가지 하드웨어 버전을 대상으로 하지만, 버전 2에 사용할
Waveshare ESP32-S3-LCD-3.16 보드가 아직 도착하지 않았다. 실물이 없는 상태에서
버전 2의 RGB LCD 초기화, 핀 설정, PSRAM, 화면 방향 및 입력 장치 동작을
완료했다고 판단할 수 없다.

현재 사용할 수 있는 버전 1 하드웨어는 다음과 같다.

- ESP32-S3 Super Mini
- 1.8인치 160 × 128 SPI TFT LCD
- ST7735S LCD 컨트롤러
- 외부 스위치 2개

## 결정

초기 제품 구현과 AI 에이전트 비교 실험은 버전 1만을 기준으로 진행한다.

- 최초 제품 요구사항과 합격 기준은 버전 1을 대상으로 작성한다.
- 데이터 모델과 공통 애플리케이션 로직은 향후 버전 2에 이식할 수 있도록
  하드웨어 의존 코드와 분리한다.
- 버전 2 전용 펌웨어와 실제 동작 검증은 보드 도착 후 진행한다.
- 버전 2가 없는 동안에는 해당 보드의 빌드 성공이나 하드웨어 동작을 초기 단계
  합격 조건에 포함하지 않는다.
- 버전 2의 세부 구현을 미리 추정하여 기준 구현에 포함하지 않는다.

## 초기 개발 범위

버전 1에서 우선 검증할 범위는 다음과 같다.

1. ESP-IDF 프로젝트 생성과 재현 가능한 빌드
2. ESP32-S3 Super Mini 업로드 및 시리얼 로그 확인
3. ST7735S LCD 초기화와 화면 방향·색상 검증
4. 외부 스위치 2개의 입력과 디바운싱
5. Wi-Fi 연결, 시간 동기화와 재연결
6. Codex 개인 사용량 데이터 수신 및 표시
7. 글로벌 리셋 데이터 수집 및 표시
8. 캐시, 오래된 데이터 및 오류 상태 표시
9. 장시간 동작과 네트워크 장애 복구 검증

## 영향

- 에이전트별 최초 구현 비교에서 버전 2 지원 여부는 평가하지 않는다.
- 버전 1의 작은 화면에 적합한 UI가 최초 디자인 기준이 된다.
- 공통 로직과 하드웨어 추상화의 품질은 향후 버전 2 이식 시 다시 평가한다.
- 버전 2 보드가 도착하면 별도의 bring-up 과제와 이식 실험을 수행한다.

## 버전 2 재개 조건

다음 조건을 충족하면 버전 2 개발을 시작한다.

- Waveshare ESP32-S3-LCD-3.16 실물 확보
- 보드 리비전 확인
- 전원 인가 및 제조사 기본 펌웨어 동작 확인
- USB 업로드와 시리얼 연결 확인
- 공식 회로도, 핀맵 및 ESP-IDF 예제 버전 확보

## 미결정 사항

- 버전 1의 정확한 GPIO 핀 배치
- ST7735S 모듈의 탭 색상과 초기화 변형
- LCD 백라이트 제어 방식
- 두 스위치의 구체적인 짧게/길게/동시 누름 동작
- 버전 1 케이스, 전원 및 물리 배치
