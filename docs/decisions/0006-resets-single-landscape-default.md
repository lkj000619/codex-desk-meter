# ADR-0006: 글로벌 리셋 단일 출처와 가로 기본 화면

- 상태: 제안 (검토 중, R1 동결 대기)
- 결정일: 2026-09-18

## 배경

pilot 펌웨어의 글로벌 화면은 `codex-reset.com`과 `codex-resets.com` 두 출처를
나란히 표시했다. 실물 사진 기준으로 정보가 분산되어 읽기 어려웠고, 소유자는
`codex-resets.com` 단일 출처와 "리셋 후 경과 시간 또는 default 화면"을 요구했다.
LCD는 320 × 820 세로 기준으로 계약되어 있었으나 실물은 가로 배치가 가독성이
높았고, IMU(QMI8658)로 방향 대응이 가능했다.

## 결정

1. 글로벌 리셋 표시 계층은 `codex-resets.com` 단일 출처를 사용한다.
   `codex-reset.com` 전망(24h/48h)은 E2E 표시 범위 밖으로 두고, 파서 호환을 위해
   스키마·fixture에는 남긴다.
2. 리셋 기록이 없으면 마지막 리셋으로부터의 경과 시간 또는 기본(default) 화면을
   표시한다. 경과 시간을 알 수 없으면 default 화면을 표시하고, 빈 화면이나 0
   시각으로 두지 않는다.
3. 기본 화면 방향은 가로(820 × 320)다. C2 합격 판정은 가로 UI 잘림 없음으로 한다.
4. IMU 기반 자동 회전을 허용한다. 회전해도 세 화면의 정보가 손실되지 않아야
   하며, 미구현은 핵심 불합격이 아니다.

## 이유

- 단일 출처 + 경과 시간은 한 화면에 담기는 정보 밀도와 가독성이 높다.
- 가로 배치는 책상 위 시청 거리에서 글자 크기를 키울 수 있다.
- IMU 회전은 Version 2 전용 자율 기능으로 분리 가능해 Version 1 이식에 영향을
  주지 않는다.

## 제약과 영향

- C4(최근 리셋·경과), C5(정보 없음 → 경과/default), C6(단일 출처 명시)의 정의가
  변경된다. C ID는 유지하므로 스키마·집계 키는 그대로다.
- F7(글로벌 리셋 표시)과 평가표 C3~C6의 기대값이 함께 변경된다.
- 기존 pilot 결과(두 출처 표시)는 본 결정 이전 자료로만 취급하고, 새 E2E cohort의
  합격 증거로 사용하지 않는다.
- 본 ADR의 승인과 baseline commit·hash 동결은 R1 종료 조건이다. R10은
  `not_authorized`로 유지한다.
