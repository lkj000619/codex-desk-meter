# ADR-0004: 초기 bring-up의 ESP-IDF를 v5.3.2로 고정

- 상태: 승인
- 결정일: 2026-09-11

## 배경

Waveshare ESP32-S3-LCD-3.16의 출고 `RGB_Demo` 부팅 로그에서 ESP-IDF
`v5.3.2-dirty`가 관찰됐다. 개발 PC에는 기존 ESP-IDF 환경이 없었으므로 첫
bring-up과 제조사 예제 검증에 사용할 정확한 버전을 정해야 했다.

## 결정

Version 2의 초기 bring-up과 에이전트 비교 실험 기준 버전을 ESP-IDF v5.3.2로
고정한다. 설치 위치는 `C:\Espressif`로 통일한다.

## 이유

- 출고 펌웨어와 같은 릴리스 계열이라 제조사 초기화 코드와 설정을 비교하기
  쉽다.
- ESP32-S3 공식 예제가 전체 빌드되는 것을 개발 PC에서 검증했다.
- 모든 에이전트에 같은 버전을 제공해 프레임워크 차이를 실험 변수에서 제외할
  수 있다.

## 제약과 영향

- Windows의 한글 경로 문제를 피하기 위해 프로젝트·빌드 도구에는 ASCII 경로를
  제공한다.
- 현재 기준 환경에서는 ccache를 비활성화한다.
- 최신 ESP-IDF로의 업그레이드는 별도 호환성 검증과 ADR을 거친다.
- LVGL과 Waveshare 컴포넌트 버전은 제조사 예제 확보 후 별도로 고정한다.
