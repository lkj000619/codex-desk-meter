# Version 2 하드웨어 기능 카탈로그

## 목적

이 문서는 AI 에이전트가 Waveshare ESP32-S3-LCD-3.16의 실제 하드웨어 자원을
동일한 조건에서 검토하도록 제공하는 고정 입력 자료다. 에이전트는 이 목록에서
제품에 유용한 기능 후보를 스스로 발굴할 수 있지만, 핵심 Codex 사용량·리셋
표시 요구사항을 대체해서는 안 된다.

## 사용 가능한 자원

| 자원 | 확인된 사양 | 에이전트 실험에서의 취급 |
|---|---|---|
| MCU | ESP32-S3R8, dual-core LX7, 최대 240MHz | 공통 연산 및 네트워크 처리 |
| 메모리 | 16MB Flash, 8MB Octal PSRAM | UI 자산·캐시 사용 가능. 메모리 예산을 기록해야 함 |
| LCD | 3.16인치, 320 × 820, RGB565, ST7701 | Version 2 기본 출력 장치 |
| IMU | QMI8658, 3축 가속도계 + 3축 자이로 | 동작·자세·제스처 기반 기능 후보에 사용 가능 |
| RTC | PCF85063, 별도 RTC 배터리 커넥터 | 네트워크 단절 중 시간 유지 기능 후보에 사용 가능 |
| 배터리 | 3.7V 리튬 배터리 충·방전 커넥터, 전압 ADC 예제 | 전원 상태 표시 기능 후보에 사용 가능 |
| 저장장치 | TF 카드 슬롯, FAT32 사용 | 캐시·로그·화면 자산 기능 후보. 현재 카드는 미장착 |
| 입력 | 프로그래밍 가능한 BOOT 버튼 | 짧게·두 번·길게 누르기 구분 가능 |
| 리셋 | RST 버튼 | 시스템 리셋 전용. 일반 제품 입력으로 재정의하지 않음 |
| 전원 | 슬라이드 전원 스위치 | 전원 ON/OFF 용도 |
| 무선 | 2.4GHz Wi-Fi, Bluetooth 5 LE | Codex 데이터 통신 또는 선택 기능 후보 |
| 확장 | UART, I2C, USB 헤더 | 기본 실험에서는 외부 부품을 추가하지 않음 |

## 실제 확인 상태

- 16MB Flash와 8MB PSRAM 초기화 성공
- ST7701 화면 출력, 방향, 기본 색상과 백라이트 확인
- QMI8658 ID와 가속도계·자이로 self-test 성공
- 화면에서 RTC와 가속도 값 갱신 확인
- BOOT 입력에 따른 메트릭·이미지 인터페이스 전환 확인
- RST 입력 후 COM3 재열거와 정상 재부팅 확인
- TF 카드 미장착 상태에서 `ESP_ERR_TIMEOUT (0x107)` 확인

## 자율 기능 선택 규칙

에이전트는 위 자원 전체를 검토하고 기능 후보를 제안한다. 후보는 다음 조건을
모두 만족해야 한다.

1. 실제 보드에 존재하는 자원을 사용한다.
2. Codex Desk Meter의 책상 위 사용 경험이나 안정성을 개선한다.
3. 추가 하드웨어 없이 재현할 수 있다.
4. 동작 여부를 로그, 자동 테스트 또는 사용자 확인 절차로 판정할 수 있다.
5. 핵심 사용량·리셋 표시 기능을 제거하거나 약화시키지 않는다.
6. 인증 정보나 비공개 계정 데이터를 새로 요구하지 않는다.

Version 2 전용 기능은 공통 핵심 기능과 분리한다. 예를 들어 IMU를 선택한
에이전트가 있더라도 IMU가 없는 Version 1의 합격 여부에는 영향을 주지 않는다.

## 주의사항

- QMI8658의 원시값만 표시하는 것은 제조사 데모 반복이므로 제품 가치와
  사용자 동작이 추가되어야 자율 기능으로 인정한다.
- PCF85063은 RTC 백업 배터리 장착 여부와 초기 시각 설정 방식을 명시해야 한다.
- TF 카드 기능은 카드 미장착 상태에서도 장치가 정상 동작해야 한다.
- BOOT는 다운로드 모드 진입에도 쓰이므로 부팅 시 눌림 상태를 안전하게
  처리해야 한다.
- BLE나 외부 인터페이스를 사용하더라도 비밀키를 펌웨어에 하드코딩하지 않는다.
