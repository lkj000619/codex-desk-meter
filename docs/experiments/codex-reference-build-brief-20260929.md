# Codex 기준 제품 제작 요청

사용자가 직접 요청한 목적: Codex로 Codex Desk Meter를 먼저 만들어 실제 기준
제품을 확보한다. 이후 다른 에이전트에 동일한 최초 프롬프트·문서를 제공해 첫
결과와 기준 제품 수준에 도달하는 수정 비용을 비교한다. 이번 작업은 기준 제품
제작이며 단회 순위 실험이 아니다. 제품 구현을 시작할 권한은 이미 주어졌다.

이 작업공간은 시작 문서본 `aab0d493888f4fc0bb6eff726bfe7d93b167543c`에서 만들었다.
그 commit의 `experiments/prompts/version-2-agent-task.md`와 제품·하드웨어·환경
문서를 제품 요구의 출발점으로 읽고, ESP-IDF v5.3.2 / Waveshare ESP32-S3-LCD-3.16
대상 펌웨어와 PC 수집·송신 프로그램을 작성하라. 이 작업은 기준 제품 개발이므로
prompt의 AGY 전용 권한 파일, runner-only 전달, 단회·후속 지시 금지, R0~R10 승인
절차와 사전 제공 run-context/manifest 요구는 이번 reference 제작의 실행 gate가
아니다. 필요한 제품 입력과 fixture는 보존하라. 이 운영 안내는 후보 비교의 공통
프롬프트가 아니며, reference 제작을 정식 비교 실행으로 주장하지 말라.

## 실행

- 제품 코드를 작성하고 실행 가능한 펌웨어, PC 송신 명령과 의미 있는 시험을 남겨라.
  문서 상태 점검이나 새 승인 절차 작성만으로 종료하지 말라. 새로운 PRD·constitution·
  설계 승인 순환을 시작하지 말라. 이미 명시된 제품 목표를 구현하라.
- 같은 저장소의 다른 브랜치·AGY 결과·후속 보완 코드·평가 자료는 읽거나 복사하지
  말라. 독립 Codex 작성 제품을 만든다. 제조사 자료는 문서에 고정된 입력을 사용한다.
- 파일 조회·생성·수정, 빌드·시험에 필요한 명령을 사용하라. 전역 설정·계정·권한
  정책을 변경하지 말라. 하드웨어 포트를 열거나 flash/erase하지 말라. 업로드와 실물
  관측은 제품을 빌드한 뒤 운영자가 수행한다.
- Windows 한글 경로를 피하려면 작업공간에 대응하는 ASCII 경로 alias를 만든 뒤
  그 안에서 빌드하라. 설치된 ESP-IDF와 pinned host toolchain을 재사용한다.
- 문서의 fixture를 PC에서 읽고 실제 직렬 frame으로 보내는 실행 가능한 경로를
  제공한다. 테스트 수치를 실제 계정 잔여량이라고 표시하지 않는다. 실제 계정 수집은
  별도 지원 상태와 이유를 명시하고 자격증명이나 숨겨진 source를 추측하지 않는다.
- LCD 표시·BOOT·전송과 회복 동작을 구현하고 자동 시험하라. 자동 시험으로 확인한
  것과 실물에서 아직 확인하지 않은 것을 나누어 기록하되, 실물 미확인이라는 이유로
  제품 작성과 빌드를 중단하지 말라. 새 요구를 발견하면 구현·제약을 기록하고 계속하라.
