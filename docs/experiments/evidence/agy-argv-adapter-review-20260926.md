# AGY explicit prompt adapter review

R02 sent the real fixed prompt through stdin but AGY returned empty prompt, zero turns/usage. Text-mode stdin is therefore unsuitable. R03 inline adapter is bound by semantic profile hash and reads original stdin bytes once, decodes UTF-8, passes exactly one --print=VALUE argument with shell disabled and child stdin DEVNULL. A real fake-CLI subprocess test with the full 9775-byte prior prompt verified exact Unicode/newline/quote preservation, no duplicate stdin and exit-code 7 propagation. No model call was used for this test. The runner remains unchanged; its timeout kills the adapter and child tree. Model, permissions, baseline and source prompt are unchanged. Different run ID substitution is expected. This changes transport of prompt, not its content. Prior diagnostic and failed runs remain recorded. Actual model and tooling behavior must be judged after this pilot.
