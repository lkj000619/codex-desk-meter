# Luna 최초 검은 화면 원인 분석

목표: 사용자 요청에 따라 COM3에 설치한 Luna 최초 원본의 검은 화면·serial 무응답이 어느 경계에서 발생하는지 확인한다.
상태: 2026-10-06 원인 분석 완료, 수정 펌웨어의 인과 검증은 미실행. 정상 부팅·PSRAM·USB 준비와 frame0 수락을 확인하고 설정 후 LCD 재리셋·지원 근거 없는 축 교환/물리 timing 결함을 기록했다. [분석 보고서](../../results/formal-comparison-20261004/luna-black-screen-diagnosis-20261006.md)에 확정 사실·유력 원인·추가 검증을 구분한다.
원본: [현재 상태](../experiments/next-comparison-readiness.md) · [운영 계약](../experiments/comparison-operating-contract.md) · [최초 평가](2026-10-06-codex-luna-initial-evaluation.md).

- [x] 동결 source·SDK/제조사 코드·설정과 원본 flash/capture를 비교한다. Application 기동→LCD 초기화→USB 수신→화면 출력의 경계를 확인한다.
- [x] 현재 COM3의 상태를 기록하고 기존 펌웨어의 로그/ROM 응답을 수집한다. 필요 시 reset 등 진단 조작과 상태 변화를 기록한다. 후보 모델 호출·source 수정·rebuild·새 펌웨어 업로드는 하지 않는다.
- [x] 증거에 맞는 단일 가설을 최소 조작으로 검증한다. 정적 결함·실물 확인·미확정 원인을 구분하고 변경 전후 진단 상태를 보존한다. 리셋부터 읽기로 부팅 실패 가설을 좁혔으며, 수정 전후 실물 시험은 추가 작업으로 명시했다.
- [x] 원본 평가·비용·동결 ref를 보존한 날짜 있는 진단 결과와 재개 상태를 연결한다.

완료 조건: 관측 증거로 실패 경계와 원인을 설명하거나, 미확정 가설 및 이를 판별하는 데 필요한 구체적 추가 관측을 기록한다. 진단 조작을 원래 공통 평가나 새 후보 실행 비용으로 집계하지 않는다. 후보 구현 수정과 비교 후속 실행은 이번 원인 분석의 완료와 별도다.
