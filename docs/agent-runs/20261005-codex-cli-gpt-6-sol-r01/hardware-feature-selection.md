# 온보드 기능 선택

보드 사실은 `docs/hardware/version-2-capabilities.md`와 그 문서가 지정한 제조사 파일을 기준으로 했다. 핵심 PC→USB→LCD 기능과 별도 모듈인 `main/feature.c`에 선택 기능을 두었다. 후보는 아래 정확히 세 가지다.

| 후보 | 사용자 가치 | 자원 | 구현 비용 | 위험 | 검증 | 결정 |
|---|---|---|---|---|---|---|
| F9-A: 유휴 시 백라이트 감광 | 갱신이 끊긴 동안 전력과 눈부심을 줄이면서 데이터를 계속 읽을 수 있다 | GPIO6 active-low LEDC PWM, uptime | 작은 상태기계 | 극성을 틀리면 어두워지지 않거나 화면이 꺼짐 | host 60초 경계·복귀 시험, 운영자 30초 켜짐/감광 관측 | **선택**. 추가 부품·시각 동기화가 필요 없고 핵심 데이터 경로와 독립적이다. |
| F9-B: QMI8658 회전 | 책상 거치 방향에 따라 자동 회전 | I2C 7/15, 주소 0x6B, 센서 poll | 센서 드라이버·방향 debounce·화면 좌표 재배치 | 흔들림에 따른 반복 회전과 RGB framebuffer 방향 충돌 | 실제 보드 4방향·흔들림·복귀 시험 | 탈락. 가로 820×320 레이아웃의 안정성을 먼저 확인해야 한다. |
| F9-C: PCF85063 로컬 시각 | USB가 끊겨도 경과 시각을 계속 표시 | I2C 7/15, 주소 0x51, backup 전원 | RTC 초기화·설정·시계 신뢰도 표시 | backup 전원 유무가 미확정이고 잘못된 RTC가 오래된 source를 새 것처럼 보이게 할 수 있음 | 전원 분리·재부팅·backup 유무·UTC 오차 시험 | 탈락. 운영자가 backup 전원 상태를 확인하기 전 시계 신뢰를 주장할 수 없다. |

선택 기능은 마지막 정상 프레임 수신 뒤 uptime 60초부터 밝기 200/255→100/255로 낮추고 새 정상 프레임이 오면 즉시 복귀한다. GPIO6은 active-low이므로 LEDC duty는 `255-brightness`다. 화면은 꺼지지 않는다. 이 선택은 제조사 데모의 임의 색상/밝기 토글을 반복한 것이 아니라 데이터 링크 유휴 상태에 연결한 제품 기능이다. `host/test_feature.c`는 경계와 복귀를 검증한다. 실물 밝기와 30초 유지 여부는 운영자 관측이 필요하다.
