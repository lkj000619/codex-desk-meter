Candidate A: Implementation & Embedded Handoff Notes

Design Intent: HUD Telemetry Matrix — Extreme high-density cockpit aesthetic for engineers desiring immediate insight into rate limiting, rolling windows, and uncoupled session token activity without visual ambiguity.

RGB565 Palette Dark BG: #05080c (0x0841), Panel BG: #071322 (0x08A4), Cyan Accent: #38bdf8 (0x3DF7), Blue Primary: #0284c7 (0x0438), Slate Muted: #64748b (0x63B1), White Text: #f0f6fc (0xF7BE).

Font Scaling Large Numbers: 38px (ASCII 28×38 glyph bitmap, ~1KB per glyph), Medium: 18px (12×18), Labels/Body: 10px–11px (8×12 standard monospaced font ROM).

Redraw Optimization Top and Bottom bars are static 28px/24px rows. Central 820×268px is subdivided into dirty rects: 5h Quota Box (420×120), Weekly Quota Box (420×110), Session Ledger (358×240). Partial PSRAM dirty rect DMA transfers minimize bus load on ST7701.
